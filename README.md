# Проф Перетяжка 63

Статический интерфейс сайта и Node.js API для отправки заявок с фотографиями на `sagatel.petrosyan@yandex.com`.

## Локальный запуск

1. Установите Node.js 20 или новее.
2. Выполните `npm install`.
3. Скопируйте `.env.example` в `.env` и укажите пароль приложения Яндекса в `SMTP_PASS`.
4. Проверьте почтовое подключение командой `npm run verify-email`.
5. Запустите сайт командой `npm start` и откройте `http://localhost:3000`.

Основной пароль от Яндекса использовать нельзя. Создайте отдельный пароль приложения для Почты. Файл `.env` исключён из Git и не должен публиковаться.

## Публикация

Проект должен запускаться на хостинге с поддержкой Node.js 20+. Команда запуска: `npm start`. В настройках хостинга добавьте переменные из `.env.example`, установите `NODE_ENV=production` и укажите публичный адрес сайта в `ALLOWED_ORIGINS`.

Обычный GitHub Pages не запускает серверный API. Если сайт сейчас опубликован через GitHub Pages, его нужно перенести на Node.js-хостинг либо отдельно опубликовать API и изменить адрес запроса на клиенте.
